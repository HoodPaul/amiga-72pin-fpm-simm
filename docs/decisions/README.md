# Decision records

Use `NNNN-short-description.md` for significant choices. Record date, status,
context, evidence, decision, alternatives, consequences and remaining checks.
Label retrospective records explicitly; do not invent original approval dates.
A proposed record does not authorise a new circuit, order or manufacturing upload.

- [0001: Preserve the manufactured A7 baseline and separate evidence](0001-a7-baseline-and-evidence.md)

Keep assembly values in the BOM/assembly documents and manufacturing settings in
the fabrication record. Decisions explain why; they do not create competing specs.
