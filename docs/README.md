## Maintenance

Update each subject in its authoritative document and link from summaries.
Preserve dated reports; new measurements need their own provenance. A status
update does not require regenerating CAD or fabrication exports. Mark proposals,
owner reports, archived checks and measured outcomes explicitly.

This public repository must not contain private tracking links, order/account
identifiers, addresses or credentials. No software production server, API
subscription, website deployment or application database belongs to this project.
